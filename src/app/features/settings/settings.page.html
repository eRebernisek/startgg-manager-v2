start.gg API token

Create a personal token at start.gg → Developer Settings. Required to edit (report sets, seeding, …). Viewing brackets works without it. Stored only on this device. Tournaments where your account is an admin can be edited; everything else stays read-only.

start.gg website session Unofficial

Adding, renaming and removing attendees is not in start.gg’s public API. The app does it the way start.gg’s own Attendees page does, through the website API, which accepts your logged-in website session (the gg_session cookie) instead of the API token. To get it: log in on start.gg in a desktop browser, open DevTools → Application (Storage) → Cookies → https://www.start.gg, and copy the value of gg_session.

The session is as powerful as your password-protected login: anyone with it can act as you on start.gg. It is stored only on this device and sent only to start.gg (or to your own proxy below). Logging out of start.gg ends it.

Without a token

View-only mode uses start.gg’s website GraphQL (same approach as TournamentStreamHelper) — no personal API token and no shared API key. Browsers cannot call that endpoint directly (CORS), so production web builds go through the small forwarder in proxy/. Android and local npm start (/sgg-public) talk to it without that Worker. Editing still needs your personal API token (and admin rights).
