SGG Manager · Effective 9 November 2026

Privacy policy

Not affiliated with, endorsed by, or sponsored by start.gg or Smash.gg. SGG Manager is an independent third-party tool.

This policy describes the Android app SGG Manager (gg.startmanager.app) and the website build of the same project. The developer does not operate an account system, analytics service, advertising service, or crash-reporting backend, and does not collect or sell personal data.

Data the developer collects

None. There is no developer account, and the app does not send usage data to the developer.

The app does not include analytics, advertising, or crash-reporting SDKs.

Data stored on your device

If you choose to use editing features or change settings, the app stores the following on the device only (Android: Capacitor Preferences; website: the browser’s local storage). View-only use does not require any of it.

  • An optional personal start.gg API token that you paste in Settings.
  • An optional start.gg website session (gg_session) that you paste in Settings.
  • App settings, such as language and, on the website build, an optional proxy URL.

Android backup is turned off (android:allowBackup="false"), so this data is not copied into Android cloud backup. Uninstalling the app deletes it.

Where that data is sent

Requests are sent only when you use the app, over HTTPS. The personal API token and website session are sent only to start.gg, and only for the features that need them (reporting sets, seeding, and entrant changes). They are not sold, not used for advertising, and not shared by the developer for analytics.

  • Android. The app calls start.gg directly. A proxy is not required and is not used.
  • Website. Browsers cannot call start.gg’s website API from another site, so the website build may send those requests through a CORS proxy that forwards them to start.gg. The proxy included with this project does not store or log the request. You can replace that proxy URL in Settings. The proxy is not part of the Android app.

Tournament, bracket, and player information shown in the app comes from start.gg and is handled by start.gg under its own policies.

Sharing

The developer does not share user data with third parties. The only destination for credentials and for the requests you make is start.gg (on the website, via a pass-through proxy as described above).

Deletion

You can delete data stored by the app at any time:

  • In Settings, use Remove token and Remove session.
  • Uninstall the app. That removes the on-device token, session, and settings.

The developer has no copy to delete. To remove data start.gg holds about your start.gg account, use start.gg’s own account controls.

Children

SGG Manager is not directed at children under 13. The suggested audience is 13 and older. The app does not knowingly collect personal information from children.

Security

Traffic to start.gg uses HTTPS. The Android app requests only the android.permission.INTERNET permission. No independent security review has been performed.

Contact

Questions about this policy: GitHub issues for this project.
